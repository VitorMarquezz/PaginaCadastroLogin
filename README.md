# PaginaCadastroLogin
Nesse projeto, criei uma pagina web de cadastro e login com ReactJs, um banco de dados com o MongoDB e uma API com o NodeJS. Utilizei as bibliotecas Axios e Prisma, para facilitar a intereção com o banco de dados e da pagina web com a API. Além disso utilizei Tokens e senha Criptografadas.
